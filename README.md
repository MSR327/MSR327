**"Why am I doing this by hand?"**

- 🏥 KGP hospital OPD slots disappear the moment booking opens. → [**KGP OPD**](https://github.com/MSR327/kgp-opd) books one the instant it opens. It's now a double-click app for Mac and Windows, so friends can use it too.
- 📚 Every OA question people share in placement chats gets buried under hundreds of messages. → [**Arigatho**](https://github.com/MSR327/Arigatho) reads the chats every day and turns them into a [searchable site](https://msr327.github.io/Arigatho/), sorted by company, with the closest practice problem for each question.

**"What if…?"**

- 🧠 …one large language model ran across a few ordinary devices at once? → [**edge-swarm**](https://github.com/MSR327/edge-swarm) splits the layers between them (pipeline parallelism).
- 🚗 …a car could drive from camera + LiDAR + spoken directions? → my B.Tech thesis: an agent in the CARLA simulator trained with PPO.
- 🎮 …an agent learned Clash Royale just by watching the screen? → [**AlphaGO_ClashRoyale**](https://github.com/MSR327/AlphaGO_ClashRoyale), very early and very fun.
- ⚔️ …practising Codeforces was a live race? → [**Codeforces Lockout**](https://github.com/MSR327/Codeforces-Lockout-Platform) picks balanced problems and ranks players as they solve.
- 🧩 …Sudoku is secretly an exact-cover problem? It is. → a [**Dancing Links solver**](https://github.com/MSR327/sudoko-solver-using-dancing-links-algorithm) in C++.
- 📈 …a trading simulator sat on a time-series database? → [**Market Analytics Platform**](https://github.com/MSR327/Temporal-Financial-Market-Analytics-Platform) on TimescaleDB.
